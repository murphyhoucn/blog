New Zotero 7

对于论文整理与管理常用的软件有：
EndNote
Mendeley
Zotero

前两者其实我都没有用过，而Zotero因为是开源软件，且有插件市场丰富，所以我一直都是选择的Zotero。

Zotero 6

Zotero已经用了有大概四五年的时间了吧，一直都是用到Zotero 6的版本。
说一下我常用的插件

  • zotero-night： https://github.com/tefkah/zotero-night
    • night model, 感觉白色太刺眼了了
    • Zotero 7 版本已经原生支持Dark模式了，所以在7中，也不再使用。
  • Zotfile： https://github.com/jlegewie/zotfile
    • 文献库中的文章PDF会默认保存在C:\Users\cosmi\Zotero\storage,利用Zotero的云存储同步的时候会一起上传上去，让本就不大的云存储空间雪上加霜。利用主要ZotFile把加入的文章能进行Move and Rename。
    • 我选将PDFMove到D:\Document\EResource\aPaperReading,然后利用坚果云对这个文件夹进行云存储同步。
    • Zotero的云同步只会同步一个类似于“超链接”的东西，在Zotero打开Item的时候，自动根据这个超链接去索引PDF。这样可以有效利用Zotero的云存储的5GB空间。
    • 不再支持Zotero 7，https://zotero-chinese.com/plugins/deprecated
  • Zotero-style： https://github.com/MuiseDestiny/zotero-style
    • 功能很多。
    • 最喜欢跟EasyScholar联动的“期刊标签”功能。
    • 阅读进度。
    • 有个缺点是功能太多了，学习成本很高，并且也会拖累Zotero的运行速度。
    • 在Zotero 7中，会很大拖累运行速度，并且现在又很多BUG，我遇到了列宽和列序会在重开软件后会自己跳变，类似的Issues看到了很多，所以在7中也没有使用该插件。
  • ZoteroIF： https://github.com/qnscholar/zotero-if
    • 使用Zotero对论文做标记本质上可能是“打标签”，并将数据保存在数据库中，并不是真正将标记写到PDF中。所以我用该插件将在Zotero中做的高亮等笔记，直接写进PDF中，从而完成对PDF的修改。
    • 该插件的最新版本(2025.10.04)目前还不能实现在Zetero7中将标记写入PDF。https://github.com/qnscholar/zotero-if/issues/16

Zotero 7

Zotero 7已经出来好久了，但因为最需要的Zotfile已经停止维护，不支持7版本的，所以对于7的升级，我一直没有提上日程。
最近打开Zotero，一直在提醒我升级到Zotero 7版本，起初我并没有理会，后来我查了一下大家的评价，网络上对其评价还不错，比老版本流畅了很多，所以我决定开始升级到7版本！

使用配置

先说一下我的基本配置。我是登录的Zotero的账户，然后使用Zotero的云同步功能来进行多设备间同步。尽管其只有300M的云空间，但如果不同步PDF文件的话，我用了大概四五年也只有了20%的空间，本着“原厂”比“副厂”稳定的原则，我暂时还是先用的Zotero自己的云空间。后面如果需要的话，迁移到坚果云的WebDAV上也很方便！

插件配置

zotero-reading-list

  • https://github.com/Dominic-DallOsto/zotero-reading-list
  • 之前在用的是Zotero自带的Tag, 现在用这个插件来标记论文的阅读状态。

Attanger

  • 代替Zotfile：https://www.reddit.com/r/zotero/comments/1g947cd/zotfile_incompatible/
  • wileyyugioh/zotmoov: Zotero plugin to automatically move attachments and link them
    • 没使用这个，不知道好不好用
  • MuiseDestiny/zotero-attanger: Attachment Manager for Zotero
    • 我选择了Attanger✅

我采用的重命名规则

zotero-ccf-info

  • TimeTrapzz/zotero-ccf-info: Zotero plugin for quick access to paper CCF rating, conference/journal, and citation count.
  • 没有了Style的“期刊标签”，我选择了这个插件了。虽然只有CCF，但对我来说也差不多够了。
  • 通用是也提供了引用数的功能。

Better Notes for Zotero

  • windingwind/zotero-better-notes: Everything about note management. All in Zotero.
  • 对我来说还是轻微的写写画画，我主要还是在用飞书云文档来整理论文笔记。

Zoplicate

  • Detect and manage duplicate items in Zotero.
  • ChenglongMa/zoplicate: A plugin that does one thing only: Detect and manage duplicate items in Zotero.
  • 管理重复添加的论文。
